<h2><a href="https://www.geeksforgeeks.org/problems/number-of-occurrence/1">Count Occurrences in Sorted</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Given a sorted array <code>arr[]</code> and a number <code>target</code>, find the number of occurrences of <code>target</code> in the given array.</p>

<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [1, 1, 2, 2, 2, 2, 3], target = 2</span></p>

<p><strong>Output:</strong> <span class="example-io">4</span></p>

<p><strong>Explanation:</strong></p>

<p>Target = 2 occurs 4 times in the given array, so the output is 4.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [1, 1, 2, 2, 2, 2, 3], target = 4</span></p>

<p><strong>Output:</strong> <span class="example-io">0</span></p>

<p><strong>Explanation:</strong></p>

<p>Target = 4 is not present in the given array, so the output is 0.</p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [8, 9, 10, 12, 12, 12], target = 12</span></p>

<p><strong>Output:</strong> <span class="example-io">3</span></p>

<p><strong>Explanation:</strong></p>

<p>Target = 12 occurs 3 times in the given array, so the output is 3.</p>
</div>

<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &le; arr.size() &le; 10<sup>6</sup></code></li>
	<li><code>1 &le; arr[i], target &le; 10<sup>6</sup></code></li>
</ul>

<p><strong>Expected Complexities:</strong></p>

<ul>
	<li><strong>Time Complexity:</strong> O(log n)</li>
	<li><strong>Auxiliary Space:</strong> O(1)</li>
</ul>
