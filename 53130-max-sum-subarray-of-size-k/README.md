<h2><a href="https://www.geeksforgeeks.org/problems/max-sum-subarray-of-size-k5313/1">Max Sum Subarray of size K</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' /><hr><p>Given an array of integers <code>arr[]</code> and a number <code>k</code>. Return the maximum sum of a subarray of size <code>k</code>.</p>

<p><strong>Note:</strong> A subarray is a contiguous part of any given array.</p>

<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [100, 200, 300, 400], k = 2</span></p>

<p><strong>Output:</strong> <span class="example-io">700</span></p>

<p><strong>Explanation:</strong></p>

<p>arr[2] + arr[3] = 700, which is maximum.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [1, 4, 2, 10, 23, 3, 1, 0, 20], k = 4</span></p>

<p><strong>Output:</strong> <span class="example-io">39</span></p>

<p><strong>Explanation:</strong></p>

<p>arr[1] + arr[2] + arr[3] + arr[4] = 39, which is maximum.</p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [100, 200, 300, 400], k = 1</span></p>

<p><strong>Output:</strong> <span class="example-io">400</span></p>

<p><strong>Explanation:</strong></p>

<p>arr[3] = 400, which is maximum.</p>
</div>

<p><strong>Constraints:</strong></p>

<ul>
	<li><code>arr.size() &le; 10<sup>6</sup></code></li>
	<li><code>0 &le; arr[i] &le; 10<sup>6</sup></code></li>
	<li><code>1 &le; k &le; arr.size()</code></li>
</ul>

<p><strong>Expected Complexities:</strong></p>

<ul>
	<li><strong>Time Complexity:</strong> O(n)</li>
	<li><strong>Auxiliary Space:</strong> O(1)</li>
</ul>
