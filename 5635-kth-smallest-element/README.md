<h2><a href="https://www.geeksforgeeks.org/problems/kth-smallest-element5635/1">Kth Smallest</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Given an integer array <code>arr[]</code> and an integer <code>k</code>, find and return the <code>k</code>th smallest element in the given array.</p>

<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [10, 5, 4, 3, 48, 6, 2, 33, 53, 10], k = 4</span></p>

<p><strong>Output:</strong> <span class="example-io">5</span></p>

<p><strong>Explanation:</strong></p>

<p>The 4th smallest element in the given array is 5.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [7, 10, 4, 3, 20, 15], k = 3</span></p>

<p><strong>Output:</strong> <span class="example-io">7</span></p>

<p><strong>Explanation:</strong></p>

<p>The 3rd smallest element in the given array is 7.</p>
</div>

<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &le; arr.size() &le; 10<sup>5</sup></code></li>
	<li><code>1 &le; arr[i] &le; 10<sup>5</sup></code></li>
	<li><code>1 &le; k &le; arr.size()</code></li>
</ul>

<p><strong>Expected Complexities:</strong></p>

<ul>
	<li><strong>Time Complexity:</strong> O(n log k)</li>
	<li><strong>Auxiliary Space:</strong> O(k)</li>
</ul>
