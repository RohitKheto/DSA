<h2><a href="https://www.geeksforgeeks.org/problems/minimum-sum-subarray/1">Minimum Sum Subarray</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Given an array <code>arr[]</code>, find the sub-array containing at least one number which has the minimum sum and return its sum.</p>

<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [3, -4, 2, -3, -1, 7, -5]</span></p>

<p><strong>Output:</strong> <span class="example-io">-6</span></p>

<p><strong>Explanation:</strong></p>

<p>The subarray is [-4, 2, -3, -1] = -6.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">arr[] = [2, 6, 8, 1, 4]</span></p>

<p><strong>Output:</strong> <span class="example-io">1</span></p>

<p><strong>Explanation:</strong></p>

<p>The subarray is [1] = 1.</p>
</div>

<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &le; arr.size() &le; 10<sup>6</sup></code></li>
	<li><code>-10<sup>7</sup> &le; arr[i] &le; 10<sup>7</sup></code></li>
</ul>

<p><strong>Expected Complexities:</strong></p>

<ul>
	<li><strong>Time Complexity:</strong> O(n)</li>
	<li><strong>Auxiliary Space:</strong> O(1)</li>
</ul>
