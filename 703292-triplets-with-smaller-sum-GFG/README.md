<h2><a href="https://www.geeksforgeeks.org/problems/count-triplets-with-sum-smaller-than-x5549/1">Triplets with Smaller Sum</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Given an array <code>arr[]</code> of distinct integers and an integer <code>sum</code>, count the number of unique triplets of elements whose sum is strictly less than <code>sum</code>. A triplet is identified only by the three elements it contains, so different permutations of the same three elements are counted as one triplet.</p>

<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">sum = 2, arr[] = [-2, 0, 1, 3]</span></p>

<p><strong>Output:</strong> <span class="example-io">2</span></p>

<p><strong>Explanation:</strong></p>

<p>Triplets with sum less than 2 are (-2, 0, 1) and (-2, 0, 3).</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">sum = 12, arr[] = [5, 1, 3, 4, 7]</span></p>

<p><strong>Output:</strong> <span class="example-io">4</span></p>

<p><strong>Explanation:</strong></p>

<p>Triplets with sum less than 12 are (1, 3, 4), (5, 1, 3), (1, 3, 7) and (5, 1, 4).</p>
</div>
